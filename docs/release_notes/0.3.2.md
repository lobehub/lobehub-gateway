### Protocol alignment

- Align the protocol baseline with `device-gateway` commit `5025dedda2fcbf5de1dc42d4bf112cdd45ff3d24` and `agent-gateway` commit `96a31e038052a8a98e9986223a170d218c253d0f`.

- Add opt-in agent resume status hand-off: `resume` messages with `wantStatus: true` receive `resume_complete` after replay when an authoritative operation status is available.
- Query the current user with `includeCount=0` during Agent Gateway API-key authentication.
