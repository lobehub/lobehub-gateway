### Fixed

- **Resuming finished agent runs** — v1 WebSocket clients that send a resume request after reconnecting receive events after their last event ID. If the gateway has already replayed the history automatically, a delayed resume request can still retrieve the status without receiving that history twice.
- **Incomplete replay history** — clients that reconnect without requesting a replay still receive the retained history and final status. If earlier events have been evicted from the replay buffer, the gateway signals the gap before sending the completion event.

### Compatibility

- No configuration changes are required.
