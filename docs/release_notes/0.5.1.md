### Fixed

- **Device health metrics**: fixed `diskTotalBytes` and `diskUsedBytes` being dropped from `device_metrics` uploads. Both fields are now available through `POST /api/device/metrics` for disk capacity and usage display on the device page.

### Compatibility

- Both disk fields are optional and nullable. Queries omit fields that were not reported and preserve explicit `null` and valid numbers (including `0`), matching the upstream gateway.
- Older devices without disk fields remain compatible. No new configuration is required; history retention and capacity limits are unchanged.
